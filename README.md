# 📚 Library Management System

A console-based **Library Management System** developed using **Python** and **MySQL**. This project helps manage books, members, and book transactions through a simple menu-driven interface.

---

## 🚀 Features

### 📚 Book Management
- Add Book
- View Books
- Update Book
- Delete Book

### 👤 Member Management
- Add Member
- View Members
- Update Member
- Delete Member

### 📖 Transaction Management
- Issue Book
- Return Book

---

## 🛠️ Technologies Used

- Python
- MySQL
- mysql-connector-python

---

## ▶️ How to Run

1. Clone the repository.
2. Install the required package:

```bash
pip install -r requirements.txt
```

3. Configure your MySQL database in `database.py`.
4. Run the project:

```bash
python main.py
```
